# 日割り計画(2026-08-21 〜 12-28)

PLAN.md v1.2 のマイルストーンを日単位に割ったもの。**その日の「終了条件」を満たしたら、時間が余っていても終わってよい。**

## 全体ルール(毎週共通)

- **日曜は完全休養日**(予備日を兼ねる。遅れた分を取り返す日ではなく、休む日。遅れの吸収は「カット順」で行う)
- 基本リズム: **火・木 = 軽い日(約1h。C++ドリルか概念学習)/ 土 = メインの日(3〜5h。実装+セッション儀式+週次レビュー)/ 月・水・金 = 自由(何もしなくてよい)**
- 曜日は入れ替えてよい(例: 火→水)。**「週に軽い日2回+メインの日1回」の形だけ守る**
- **詰まった日の終了条件(全日共通の代替)**: 予定時間を使い切ったら、「どこで・何が分からなかったか」を1行メモ(次回ChatGPTに貼る用)して終了してよい。延長しない。罪悪感も持たない(そのためのメモ)
- 「ドリル(a)〜(e)」は docs/cpp-drills.md の対応表を指す。各ドリル日の終了条件は「2問解く(正解でなくてもよい。解説を読んで『何を知らなかったか』を1行メモしたら終了)」
- セッション儀式(メインの日の最後30分): 理解チェック3問 → interview-qa記入 → timelog記入 → コミット&プッシュ(手順: START.md §3)
- 審査会(9月中旬)・チーム制作・就活で潰れた週は、**その週のメインの日の内容を翌週に1つずつ後ろへずらす**(M1〜M2には吸収余地がある。M4以降で2週以上遅れたらPLAN.md §4のカット順を発動)
- **A-SのExitゲート**: M1〜M5の締めでは、(1)概念を説明する、(2)紙/コンソールの小課題を解く、(3)本人の言葉で説明する、(4)本体へ使う、の4つを必ず確認する。interview-qaは本人の説明を記録する。1つでも欠けたら次のMへ進まない。
- **同じ零号機へ統合**: M1はフレーム経路、M3はSceneObject経路、M4はMesh/Material経路、M5は2シーンの提出物へ段階的に置き換える。別サンプルを増やさない。ECS・汎用RenderQueue・ResourceManagerは対象外。
