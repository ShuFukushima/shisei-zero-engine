AIにコードを見せてもらった場合だけでなく、文書起草・レビュー・作業台の提供など、コミットへ反映されたAI関与を**その場で**記録する(規則の正本: AGENTS.md コード開示ルール3・決定#15)。
「再実装した日」列は、開示3回につき1回以上のペースで白紙から再実装して埋める。
ChatGPTは会話をまたぐと前回何を開示したか覚えていないため、この台帳が唯一の記録になる。

この台帳は、①選考のAI利用申告義務(ツール名+利用内容の明記)に後から再構成なしで対応するための正本である。②コミット前には「このコミットに含まれるAI関与が台帳にあるか」を確認してからコミットする(手順: docs/sourcetree-guide.md §2、docs/private/publish-guide.md)。③初回の本体コミット分も対象であり、2026-08-25〜26の公開計画・運用文書一式はClaude(Fable 5・Opus 5)が起草・全面改訂し、OpenAI Codex(GPT-5系)が敵対的レビューで指摘を行ったため、下表にそれぞれ実際のエントリとして記録してある。④「コミット前」と書いた行は、次のセッション開始時にCodexが git log から実ハッシュ先頭7桁を特定して置き換え、その置き換えはそのセッションの通常コミットに含める。ハッシュ記入だけのコミットは作らない(2026-09-02改訂。正本: AGENTS.md「AI利用の記録義務」)。
