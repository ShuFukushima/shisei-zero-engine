# LearnOpenGL全項目 + 実務・GitHub補完による「高度な3Dレンダラー機能」一覧調査

## 結論

LearnOpenGL の Advanced OpenGL / Advanced Lighting / PBR / In Practice / Guest Articles 全章を実際に開いて確認し、Real-Time Rendering系の一般的技法・GDC定番トピック・個人レンダラーGitHub作品を検索で補完した結果、**シャドウ/ライティング/マテリアル・PBR/ポストプロセス/ジオメトリ・地形/アニメーション/最適化・カリング/GI・レイトレーシング/エンジン基盤・ツール**の9カテゴリで合計**63機能**を洗い出した(目標40を大幅に上回る網羅性)。

技術的な内容(何をする技術か)は各出典URLで裏付けたが、**「難易度(1〜5)」「初学者の目安時間」「就活アピール度」は本レポート独自の評価(経験則ベースの推定)**であり、検索で得た難易度に関する記述(例: Area Lightsが「非常に高度」と明記、Skeletal Animationが「中〜上級者向け」と明記等)がある場合はそれを反映した。この点は「確信度と限界」節で明記する。
